### New Feature: Actual Token Tracking

**Schema:** `AgentOut.actual_tokens: Optional[dict]` — fields: input_tokens, output_tokens, cache_read_input_tokens, cache_creation_input_tokens, total_tokens

**Model:** `AgentBuildAgentModel.actual_tokens_total = Column(Integer, nullable=True)`

**API:** `actual_tokens` read from per-run JSON `agents[].actual_tokens` by role match

**JS Run History:** "Est / Actual" column replaces "Forecast Δ", colour-coded (green/amber/red)

**JS Token Chart:** Dashed actual datasets appended per role alongside solid estimate datasets

**JS Forecast Chart:** Actual bar uses sum of `actual_tokens.total_tokens` per run (not `total_tokens_estimated`)

**JS KPI:** Cache Hit Rate KPI card added (`ab-kpi-cache-hit`)

**aggregate_metrics.py:** `by_feature_type` avg prefers actual sum over estimated
